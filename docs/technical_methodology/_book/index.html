1 Welcome!

This book explains in-depth how our FIM code works! To calculate the FIM each month, we run fiscal_impact_BETA.R, the working replacement of fiscal_impact.R, our original FIM code.

fiscal_impact_BETA.R was written by Lorae Stojanovic in the spring of 2024. The code was completed by Sarah Ahmad and Georgia Nabors in the winter of 2025, reflecting further improvements to the data import process and our updated FIM methodology.

I recommend having this document open as you review fiscal_impact_BETA.R and each of our helper scripts. It goes through the code line-by-line. Good luck!
